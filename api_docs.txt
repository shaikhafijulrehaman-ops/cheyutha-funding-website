Cheyutha Helping Society NGO - Complete API Documentation

BASE URLS:
- Local Development: http://localhost:5000/api
- Live Production: https://cheyutha-funding-website.onrender.com/api

AUTHENTICATION:
- Login Endpoint: POST /api/auth/login
- Payload: {"password": "admin123"}
- Response: {"token": "<JWT_TOKEN>"}
- Protected Endpoints Header: Authorization: Bearer <token>

PUBLIC GET ENDPOINTS (No Auth):
1. GET /api/members - List community members
2. GET /api/programs - List NGO programs
3. GET /api/gallery - List photo albums and images
4. GET /api/sponsors - List sponsors
5. GET /api/quotes - List quotes
6. GET /api/events - List events
7. GET /api/ground-actions - List ground action stories
8. GET /api/slides - List hero slider banners
9. GET /api/certificates - List legal documents (12A, 80G, CSR, PAN)
10. GET /api/settings - List global site settings
11. GET /health - Health check

PUBLIC FORM & PAYMENT ENDPOINTS (No Auth):
